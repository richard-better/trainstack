# Design System — Pre

## Product Context

- **What this is:** Sport-specific prehab app that generates AI-personalized guided sessions for recreational athletes
- **Who it's for:** Recreational multi-sport athletes (runners, climbers, cyclists, lifters) who know they should be doing prehab but fail at home execution
- **Space/industry:** Health/fitness — prehab & injury prevention, competing with Adapted, GoWod, Pliability, StretchIt
- **Project type:** iOS-native app (Expo) + web marketing site

## Aesthetic Direction

- **Direction:** Luminous garden classicism — Maxfield Parrish light, Studio Ghibli natural detail, Jean Giraud Moebius line quality. Pixel art as the illustration rendering style.
- **Decoration level:** Intentional in-app (warm surfaces do the work); Expressive in marketing (lush garden scenes, classical statuary, rich sky blues and greens, luminous light)
- **Mood:** The app feels like a well-lit studio — warm, precise, unhurried. The marketing feels like stumbling into a classical garden at golden hour: statues in dappled light, rich greens, sky blue arching overhead. Sport as a serene, practiced discipline rather than a heroic performance.
- **Illustration style:** Pixel art rendering in the Parrish/Ghibli tradition — ancient Greek gardens, marble statuary, lush cypress trees, bright open sky. Every illustration is painterly and luminous, not flat or geometric.
- **Reference:** Maxfield Parrish's luminous palette and idealized classical spaces. Studio Ghibli's dense natural detail. Moebius's precise linework. The pixel art treatment unifies these into something ownable — no competitor is anywhere near this aesthetic.
- **Previous direction (retired):** Soviet-era sports posters / Renaissance fresco / warm earth tone mural aesthetic. Replaced 2026-04-09.
- **Approved illustration (hero):** `apps/web/public/illustrations/hero-colonnaded-garden.png` — Midjourney v8, prompt B (The Colonnaded Garden). Male athlete in warrior lunge, ancient colonnaded courtyard, amber flowering vines, warm golden-hour light. Use this as the reference for all future illustration commissions.

## Logo

- **Treatment:** Sun-disc lockup — "Pre" in Satoshi Black Italic with a terracotta sun disc sitting behind the wordmark, eclipse-style. The 'P' partially covers the sun, like a figure walking past at golden hour.
- **Rationale:** Pulls the marketing palette (golden hour, terracotta, the colonnaded-courtyard hero) into the brand mark. The italic does the motion work; the sun does the warmth and place. Scales from 16px favicon to hero size without losing identity.
- **Previous direction (retired):** Velocity-mark spec — terracotta dash (3×2px) extending from the 'e' terminal. Replaced 2026-05-02. Reason: rendering confirmed the mark was too small to register at any scale, and the italic alone was already doing the motion job. The velocity mark was solving a problem the wordmark didn't have.
- **Mark (icon-only):** Terracotta sun disc on near-black (#0F0F12) rounded square (22% radius). Used for favicons and any context where the wordmark won't fit. Font-independent — works as a raster at any size.
- **App icon (dark, primary):** Terracotta sun disc centered on near-black (#0F0F12), 'P' in Satoshi Black Italic (#EAE8E0) overlapping the lower-left of the sun.
- **App icon (light variant):** Terracotta sun on parchment (#F5EFE0), 'P' in primary text (#1A2530).
- **App icon border radius:** 22% of icon size (iOS standard).
- **Source files** (paths converted from Satoshi via fontkit, no font dependency at render time):
  - Wordmark: `apps/web/public/brand/wordmark.svg` (uses `currentColor` — inherits from host CSS)
  - App icon dark: `apps/web/public/brand/mark.svg`
  - App icon light: `apps/web/public/brand/mark-light.svg`
  - Bare mark (no bg, for splash/adaptive): `apps/web/public/brand/mark-bare.svg`
  - Monochrome silhouette (Android themed icons): `apps/web/public/brand/mark-mono.svg`
  - Favicon: `apps/web/public/favicon.svg` (sun disc only — universal rendering)
- **Native icons:** Generated from the SVG sources via ImageMagick. Sources at `apps/native/assets/images/{icon,favicon,splash-icon,adaptive-icon,android-icon-*}.png`. Re-generate from `mark.svg` / `mark-bare.svg` / `mark-mono.svg` if the brand changes; iOS/Android build artifacts are gitignored and regenerated by `expo prebuild`.
- **Never:** Reduce font weight below Bold for the wordmark. Never use upright (non-italic) for the primary logo mark. Never put the sun _in front of_ the wordmark — the 'P' eclipsing the sun is the brand gesture.

## Typography

- **Display/Hero:** Satoshi Black Italic (`font-weight: 900; font-style: italic`) — session names, marketing headlines, "Do your Pre." tagline
- **Heading:** Satoshi Bold (`font-weight: 700`) — exercise names, section headers, onboarding titles
- **UI/Labels:** Satoshi Medium (`font-weight: 500`) — button labels, nav items, form labels
- **Body:** DM Sans Regular (`font-weight: 400`) — descriptions, form helper text, notifications
- **Data/Mono:** JetBrains Mono — sets/reps/rest counts, timers, progress indicators, all numeric data
- **Loading strategy:** Fontshare CDN for Satoshi (`https://api.fontshare.com/v2/css?f[]=satoshi@900,700,500,400&display=swap`); Google Fonts for DM Sans; JetBrains Mono via Google Fonts or bundled
- **Scale:**
  - `text-xs`: 11px / 1.4 — labels, badges, mono data
  - `text-sm`: 13px / 1.5 — secondary text, captions
  - `text-base`: 16px / 1.65 — body copy
  - `text-lg`: 18px / 1.5 — emphasized body
  - `text-xl`: 22px / 1.3 — card titles, exercise names
  - `text-2xl`: 28px / 1.2 — screen headings
  - `text-3xl`: 36px / 1.1 — hero sub-headings
  - `text-4xl`: 48px / 1.0 — display, session completion
  - `text-5xl`: 64px / 0.95 — hero headlines
  - `text-6xl`: 96px / 0.9 — marketing hero only

## Color

- **Approach:** Restrained — one accent (terracotta) across both modes. Color is rare and meaningful. The palette shifts register between light and dark, but the hierarchy is identical.
- **Mode:** Light-first. Dark mode fully supported and specified below.

### Light Mode (primary)

- **Background:** `#F5EFE0` — warm parchment. Not white — it has weight and warmth.
- **Surface:** `#EDE4CF` — card backgrounds, bottom sheets
- **Surface-2:** `#E3D8BE` — elevated surfaces, input backgrounds
- **Surface-3:** `#D8CCAA` — hover states, active backgrounds
- **Border:** `rgba(0,0,0,0.08)` — subtle dividers
- **Faint:** `#C8BCA8` — disabled states, empty dots
- **Muted text:** `#8B7D6B` — secondary text, placeholders, labels
- **Primary text:** `#1A2530` — dark ground (from garden shadow palette)
- **Accent:** `#D4603A` — terracotta. The only color with energy. CTAs, active states, progress fills, velocity mark, capacity dots when filled.
- **Accent hover:** `#E8784A`
- **Accent background:** `rgba(212,96,58,0.10)` — tinted backgrounds behind accent elements
- **Secondary:** `#3D6B8C` — deep sky blue. Sparingly: info states, links, secondary CTAs
- **Success:** `#4A7A4E` — garden green. Session completion, positive capacity change.
- **Warning:** `#C8893A` — amber. AI fallback banner, low capacity regions.
- **Error:** `#C04040` — paywall gate, validation errors
- **Info:** `#4A7C8B` — new session generated, system messages

### Dark Mode (secondary)

- **Background:** `#0D1410` — near-black with a forest green undertone (not warm-neutral)
- **Surface:** `#151E18` — card backgrounds, bottom sheets
- **Surface-2:** `#1E2920` — elevated surfaces, input backgrounds
- **Surface-3:** `#28342A` — hover states, active backgrounds
- **Border:** `rgba(255,255,255,0.07)` — subtle dividers
- **Faint:** `#3A4A3D` — disabled states, empty dots
- **Muted text:** `#7A8A7D` — secondary text (cooler than previous warm-neutral)
- **Primary text:** `#EAE8E0` — warm white (not pure #FFF)
- **Accent, Secondary, Semantic:** Same hex values as light mode. Terracotta reads identically across both modes.

### Marketing Palette (garden classical)

- Parchment: `#F0E8D0`
- Sand: `#D4C4A0`
- Terracotta: `#C9623F` (slightly shifted for print/marketing)
- Sky blue: `#7BA3C0`
- Deep blue: `#3D6B8C`
- Garden green: `#4A7A4E`
- Lush green: `#6B9E5E`
- Shadow: `#2B3E52`
- Dark ground: `#1A2530`

## Spacing

- **Base unit:** 8px
- **Density:** Comfortable (not compact — sessions need breathing room; not spacious — it's a mobile workout app)
- **Scale:** 2(2px) 4(4px) 8(8px) 12(12px) 16(16px) 20(20px) 24(24px) 32(32px) 40(40px) 48(48px) 64(64px) 80(80px)
- **Standard screen padding:** 24px horizontal
- **Card internal padding:** 24px (large), 16px (compact)

## Layout

- **Approach:** Grid-disciplined — the session runner is full-bleed and sequential; the home screen uses a strict vertical stack. No decorative asymmetry in-app.
- **Mobile grid:** Single column, 24px gutter
- **Web marketing grid:** 12-column, 32px gutter, max-width 1200px
- **Border radius hierarchy:**
  - `r-sm`: 6px — chips, badges, small elements
  - `r-md`: 10px — inputs, small cards, alerts
  - `r-lg`: 16px — main cards, session blocks, bottom sheets
  - `r-full`: 9999px — buttons (pill shape), dots, toggles
  - App icon: 22% of icon dimension (iOS standard)
- **Session runner:** Full-bleed, no sidebar, no nav — the app gets out of the way when the session is running

## Motion

- **Approach:** Minimal-functional — only transitions that aid comprehension. The session runner auto-advances; that transition should feel smooth, not fancy.
- **Easing:** `ease-out` for enter, `ease-in` for exit, `ease-in-out` for state transitions
- **Duration:**
  - Micro (hover, focus): 100ms
  - Short (button press, toggle): 150ms
  - Medium (screen transition, card expand): 250ms
  - Long (session auto-advance, onboarding step): 400ms
- **Never:** Decorative entrance animations. No skeleton loading shimmer effects — use actual loading states.

## Component Patterns

### Buttons

- Primary: terracotta fill, white text, pill shape, Satoshi Bold 14px — for single primary CTA per screen
- Secondary: surface-2 fill, primary text, pill shape — supporting actions
- Ghost: transparent, muted text, subtle border — destructive or low-priority actions
- Size: standard (padding: 12px 24px), small (8px 16px)

### Capacity Rating

- 5 circular dots per region (values 0–4), filled terracotta for selected and below
- Region names: Knee, Shoulder, Hip, Back, Wrist (customize per sport)
- Label: "How much do you trust this region today?" — never "pain level"

### Session Progress

- Thin 2px progress bar (terracotta fill on faint background), no percentage label
- Exercise count shown as "Exercise 2 of 5" in mono, top of screen
- No skip button visible during exercise — only after completing a set

### Exercise Cards

- Exercise name: Satoshi Bold, 28px
- Set/rep meta: JetBrains Mono, 11px, terracotta, uppercase
- Form cues: max 3 bullets, DM Sans 13px, muted text
- Side-by-side timer + action button at bottom of screen
